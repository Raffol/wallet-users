**Кошелёк на базе Python/FastAPI**

**Разработано в рамках тестового задания**

Реализовано:
- пополнение/списание
- баланс
- тесты
- Покупки со скидками
- Купоны с проверками
- Возвраты
- История операций
- Статус кошелька
- потолок баланса
- Веб-страница

Быстрый старт: "docker compose up --build -d"
Тесты: "docker compose run --rm --entrypoint pytest app -v"
